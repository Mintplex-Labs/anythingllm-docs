## New Features

- [x] Reasoning effort controls - pick how hard the model thinks per chat for Anthropic, OpenAI, Gemini, DeepSeek, Ollama, and GenieX Engine models
- [x] Pull a model from Hugging Face straight into AnythingLLM with a deep link (`anythingllm://pull-hf?repo=unsloth/gemma-3-1b-it-GGUF&file=gemma-3-1b-it-Q4_K_M.gguf`)
- [x] Tinyscribe 0.1.0 with new speaker UI controls and improved performance
- [x] Personalized greetings on the home screen and empty chats that change with the time of day
- [x] Gemini is now available as an image generation provider
- [x] llmman is now available as an image generation provider
- [x] Firecrawl is now available as an agent web search provider

## Improvements

- [x] Onboarding updated to cover magic features, with a new privacy UI
- [x] Workspace settings now save automatically as you edit, with no more "Update workspace" button
- [x] Provider search menus now autofocus and support arrow keys, Enter, and Escape
- [x] Workspace temperature now applies to agents, and is left out of the request entirely when unset so the provider uses its own default
- [x] Temperature is no longer sent to Anthropic models (Anthropic and Bedrock), since newer Claude models reject it
- [x] OpenAI GPT models on AWS Bedrock now work in chat and agents, with native tool calling
- [x] Generic OpenAI max tokens can be set to `0` to leave `max_tokens` out of the request
- [x] TogetherAI now has a configurable max tokens setting to prevent truncated responses
- [x] SearchApi web search now returns results for all supported engines, including Google Jobs and Google Maps
- [x] Text uploads in UTF-16 and other non-UTF-8 encodings are now read correctly, falling back to UTF-8
- [x] Spreadsheet dates and times are now read as dates instead of serial numbers
- [x] Generated images are now included in chat exports
- [x] Text-to-speech now skips emoji, Markdown, and thinking blocks for cloud voices, Telegram voice replies, and the desktop assistant
- [x] GenieX bumped to 0.7.1 with token metric reporting
