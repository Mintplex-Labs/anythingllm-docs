## Notable Changes

### New Built-in Engine: Lemonade + llama.cpp

<Image
  src="/images/product/changelog/1.18.0/engine-migration.png"
  height={2212}
  width={3680}
  quality={100}
  alt="AnythingLLM built-in engine upgrade"
  style={{ borderRadius: "10px", padding: "10px" }}
/>

AnythingLLM Desktop has a new built-in engine for running models on your computer. We are moving off of Ollama and onto llama.cpp, managed by AMD's Lemonade. The new engine is smaller, faster, supports more hardware, and can run more models.

New installs use the new engine by default. If you are an existing user on the old Ollama-based engine, you'll see an **Engine upgrade** prompt in the app. The upgrade downloads a small model recommended for your computer so you can keep chatting right away, then removes the old engine and the models you downloaded with it. Your workspaces, chats, and documents are not affected.

<Callout type="info" emoji="️💡">
  **Note:** We recommend migrating as soon as possible. You'll need to re-download any models you want to use on the new engine. You can keep using the old engine for now, but a future update will move you to the new engine automatically.
</Callout>

Want to know why we made this change? Read the full write-up on our blog: [Why AnythingLLM is moving from Ollama to Lemonade and llama.cpp](https://anythingllm.com/blog/lemonade-llama-cpp).

### Reasoning Controls for Local and Cloud Models

<Image
  src="/images/product/changelog/1.18.0/reasoning-controls.png"
  height={1186}
  width={2164}
  quality={100}
  alt="AnythingLLM reasoning controls"
  style={{ borderRadius: "10px", padding: "10px" }}
/>

You can now control reasoning for supported models directly from the chat input, for both local and cloud providers. The options you see change with your provider and model, based on what that model supports. Some models offer effort levels, while others only let you turn thinking on or off or leave it at the provider default.

Not every provider publishes which of their models support reasoning or which controls they accept, so this is available only where we can detect it. If you don't see reasoning controls for a model, that provider or model doesn't expose them yet.
