## Notable Changes

### Updated browser extension

The [browser extension](https://github.com/Mintplex-Labs/anythingllm-extension) has been improved beyond its original function of just collecting documents to now a full fledged UI chat bar with the ability to right click -> Add context (text and image) and chat directly  in Chrome. This sidebar should have mostly full parity for tooling and more with the traditional chat UI.

While it is backward and forward compatible, only full functionality is expected when the server and extension are on version 1.20.0 or later. We will be updating the browser extension on the [Chrome webstore](https://chromewebstore.google.com/detail/anythingllm-browser-compa/pncmdlebcopjodenlllcomedphdmeogm) shortly after main release.

The task inbox for [Meeting Assistant](/meeting-assistant/introduction) tasks has been redesigned to make it easier to keep on top of your follow-ups.

- **Edit tasks:** open any task to change its title or due date. The editor works from both the task inbox and a meeting's **Tasks** tab.
- **Due dates with times:** pick a due date and time with your system's date picker, right from the task row. Changes save automatically.
- **Sorted for you:** tasks with a due date are listed soonest first, followed by tasks with no due date.
- **Completed tasks:** completed tasks show when they were completed. Reopen a task to change its due date.

### PowerPoint tool overhaul

The agent's PowerPoint tool has been rebuilt from the ground up to produce cleaner, better looking presentations.

- **Themes and layouts:** decks use new color themes and a set of layouts that are picked to fit each slide's content, so the same layout is not repeated slide after slide.
- **Live slide previews:** slides appear in the chat as they are built, so you can watch the deck come together. Click a preview to see it full size.
- **Grounded content:** figures, chart values and quotes are only kept when your outline, research or conversation contains them, and text is sized to fit each slide.

### Email approval cards for Gmail and Outlook

When an agent wants to send or draft an email with the [Gmail](/agent/usage/gmail-agent) or [Outlook](/agent/usage/outlook-agent) tools, the approval request is now shown as an email card. You can edit the recipients, Cc, Bcc, subject and body right in the card before you approve it. The approval timer pauses while you edit, and you can expand a sent email to see exactly what went out.

### MCP improvements

- **Identity forwarding:** MCP servers can now receive the workspace and user that is calling them. Opt in per server with `anythingllm.forwardIdentity`. See [Forwarding identity to MCP servers](/mcp-compatibility/forward-identity).
- **Per-server timeouts:** set `anythingllm.timeout` (in seconds) on an MCP server to control how long its tool calls can run. The default is 60 seconds.
- **Developer API:** new `/v1/mcp-servers` endpoints let you list, add, update, delete, start, stop and reload MCP servers, and turn individual tools on or off.
- MCP servers with many tools now load every page of tools, starting one server also picks up any newly saved servers, and disconnected servers can be deleted.
