## Notable Changes

### Built-in LLM for Docker

<Image
  src="/images/product/changelog/1.19.0/docker-built-in-llm.png"
  height={2212}
  width={3680}
  quality={100}
  alt="AnythingLLM Docker built-in LLM powered by Lemonade and llama.cpp"
  style={{ borderRadius: "10px", padding: "10px" }}
/>

AnythingLLM Docker now has a default local LLM experience right out of the box. The same kind of built-in engine that ships with [AnythingLLM Desktop](/setup/llm-configuration/local/built-in) can now run **inside the container**: [Lemonade](https://lemonade-server.ai), the fully [open-source](https://github.com/lemonade-sdk/lemonade) local inference server from AMD, running your models with [llama.cpp](https://github.com/ggml-org/llama.cpp). You no longer need to run Ollama, LM Studio or any other inference server next to AnythingLLM.

Pass your GPU into the container and the engine is accelerated on whatever hardware you have. It picks the fastest backend automatically: CUDA for NVIDIA GPUs, Vulkan for AMD and Intel GPUs, or the CPU. It runs on both `amd64` and `arm64` hosts.

When it's turned on, **Built-in** becomes the default LLM provider during onboarding, with three models recommended for your hardware. You can download any model from the model table or pull any GGUF model from Hugging Face. It works everywhere a provider can be used: the system LLM, workspace and agent LLMs, the chat window model picker, and [Model Router](/model-router/setup).

<Callout type="info" emoji="️💡">
  **The built-in LLM is off by default.** Turn it on by starting the container with `-e ENABLE_BUILT_IN_LLM=true`, and add `--gpus all` (or pass in your AMD or Intel GPU devices) for GPU acceleration. See [Built-in LLM for Docker](/installation-docker/built-in-llm) for the full setup for each kind of hardware.
</Callout>

## Improvements

- [x] Agent sessions now pick up workspace model and provider changes mid-conversation, including switching to or from a model router. A running response finishes on its original model.
- [x] Embedding attachments that are too large for the context window now shows live per-file progress, and you can remove files from the queue
- [x] Responses that hit the model's max output tokens now show a notice explaining why they stopped
- [x] The bulk link scraper now reads PDFs and other file links with the file converters, and gets transcripts for YouTube links it finds
- [x] Hungarian language support, including the desktop-only features
- [x] `.mov` video files can now be uploaded and transcribed
- [x] Screen readers now read out a reply once it has finished streaming
- [x] Clarifying question timeouts now pause once you start answering
- [x] Tool approval requests now show the email body, recipients and BCC for email tools, and the prompt for scheduled jobs
- [x] MCP tool results are now returned as plain text without the result wrapper
- [x] Weaviate now uses the v3 client (gRPC and REST) ahead of Weaviate removing GraphQL, with new options for deployment type and gRPC host and port
- [x] Bedrock now supports India (`in.`) cross-region inference profiles
- [x] Gemini and Vertex no longer send sampling and thinking parameters those models have deprecated
- [x] OpenAI image generation now defaults to `gpt-image-2.5-flare`
- [x] The assistant now uses the speech-to-text provider you selected in settings
- [x] Your name is now detected only from your operating system account
- [x] Magic Tab now calls your own Ollama server directly when it is your provider
- [x] CSV chat exports now neutralize spreadsheet formulas
- [x] Embed widget requests now have a request size limit
- [x] Web search error messages no longer include parts of your API key
- [x] The app now connects to the document processor over `127.0.0.1`
- [x] Drupal Wiki and bulk link scraper imports that find no pages are now reported as failures
- [x] The password reset screen now tells you why a reset was refused
- [x] Excel short dates are now read as ISO dates
- [x] Long citation URLs are now shortened in the citation details window
- [x] Translation fixes across multiple languages

## Bug Fixes

- [x] Fixed a crash when the prompt compressor reached history records that could not be converted
- [x] Fixed the prompt compressor dropping attachments from the current message
- [x] Fixed the OpenAI-compatible chat API losing conversation history when the prompt was compressed
- [x] Fixed token counts ignoring the text of messages that have attachments
- [x] Fixed system prompt variables expanding placeholders inside other variables' values
- [x] Fixed the file edit tool changing the line endings of files that use CRLF
- [x] Fixed GitHub and GitLab repository imports failing on branch names that contain `#`, `&` or `+`
- [x] Fixed Telegram bot agent answers being cut off when split across several messages
- [x] Fixed workspace chat settings crashing when the saved LLM provider was not in the list
- [x] Fixed Magic Beacon window shortcuts firing when a focused control already handled the key
- [x] Fixed the Visual C++ Redistributable never running during the Windows install
- [x] Fixed the window opening too small on Linux Wayland with fractional scaling
